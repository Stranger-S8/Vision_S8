# 📸 Vision_S8 Quick Start Guide
## For E-commerce Sellers

---

## What You Just Bought

**Vision_S8** is a product image analyzer that tells you:
- ✅ If your photo is good enough to sell
- ✅ If it meets Amazon/Etsy/Shopify requirements  
- ✅ Exactly what to fix to improve it
- ✅ **Which photo is better** (A/B comparison!)

**No coding required!** Just double-click and go.

---

## Step 1: Install Python (One Time Only)

1. Go to: **https://www.python.org/downloads/**
2. Click the big yellow "Download Python" button
3. Run the installer
4. ⚠️ **IMPORTANT:** Check the box that says "Add Python to PATH"
5. Click "Install Now"

---

## Step 2: Start Vision_S8

### On Windows:
Double-click: `START_VISION_S8.bat`

### On Mac:
1. Open Terminal
2. Navigate to the Vision_S8 folder
3. Run: `./start_vision_s8.sh`

**First time takes ~2 minutes to download components.**

---

## Step 3: Analyze Your Images

### 📸 Single Image Analysis
1. Your browser opens automatically to the analyzer
2. Click the **"📸 Analyze Single Image"** tab
3. Click "Upload Product Image" or drag your photo
4. Select your target platform (Amazon, Etsy, etc.)
5. Click "🔍 Analyze Image"
6. Read your results!

### 🆚 Compare Two Photos (A/B Test)
**Not sure which photo to use? Let Vision_S8 decide!**

1. Click the **"🆚 Compare Two Photos"** tab
2. Upload **Photo A** (your first option)
3. Upload **Photo B** (your second option)
4. Click "🆚 Compare Photos"
5. See which one wins and WHY!

💡 **Tip:** This feature requires NO AI - it's free to use!

## Common Issues & Fixes

### "Image too small"
**Fix:** Re-export your photo at higher resolution, or take a new photo with more megapixels.

### "Image too dark"
**Fix:** Add more lighting when shooting, or increase brightness in photo editing software.

### "Background not uniform"
**Fix:** Use a white backdrop or bedsheet, or use the background removal feature.

### "Image is blurry"
**Fix:** Use a tripod, ensure proper focus, and use good lighting.

## Need AI Features?

Basic analysis and A/B comparison are FREE. For AI-powered features (auto-enhancement, competitor comparison):

1. Get a free API key: **https://aistudio.google.com/apikey**
2. Create a file called `.env` in the Vision_S8 folder
3. Add this line: `GEMINI_API_KEY=your-key-here`
4. Restart Vision_S8

## Troubleshooting

### "Python is not installed"
Install Python from python.org (see Step 1)

### "Browser doesn't open"
Manually go to: **http://127.0.0.1:7860**

### "Something went wrong"
1. Close the window
2. Delete the `.installed` file
3. Run the start script again
